# Controle Financeiro

App pessoal de controle de despesas, entradas, cartão, metas e investimentos.
Roda direto no navegador (celular ou computador). Os dados ficam só no aparelho de quem usa.

- Para instalar no iPhone: abra o endereço no Safari, toque em Compartilhar e em "Adicionar à Tela de Início".
- Faça backup com frequência em Mais → Cópia de segurança.
